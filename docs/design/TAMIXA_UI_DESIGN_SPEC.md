# Tamixa — Ultra HD UI Design Specification

Children's bedtime storytelling app • Premium Indian aesthetic

---

## Design Philosophy

- **Emotionally safe** — Calm, reassuring for children before sleep
- **Parent-trust oriented** — Professional, trustworthy
- **Minimal clutter** — Focused, uncluttered layouts
- **Not cartoonish** — Refined, premium feel
- **Indian bedtime aesthetic** — Cultural warmth, multilingual support

---

## Color Palette

| Name | Hex | Usage |
|------|-----|-------|
| Midnight Blue | `#1E1F3F` | Primary background |
| Deep Indigo | `#2D2F6E` | Gradient, surfaces |
| Soft Gold | `#F6C453` | Primary CTAs, accents |
| Cream | `#FDF6E3` | Body text, titles |
| Lavender Glow | `#E8E0F0` | Highlights, secondary text |

**Background gradient:** `#1E1F3F` (top) → `#2D2F6E` (bottom)

---

## Typography

- **Font family:** Soft rounded sans-serif (Poppins / Nunito)
- **Style:** Elegant hierarchy, large readable titles, friendly UI
- **Primary text:** Cream `#FDF6E3`
- **Secondary:** Lavender glow, muted for terms/legal

---

## Design Tokens

- **Corner radius:** 24dp (large elements), 16dp (inputs)
- **Shadows:** Soft, subtle elevation
- **Stars:** Soft glowing points, subtle night sky texture
- **Buttons:** Warm golden with soft glow on primary CTAs

---

## Screen Specifications

### 1. Welcome Screen
- "Welcome to Tamixa" — hero title
- Child sleeping under moonlight illustration
- Mobile input: `+91` prefix, rounded field
- "Get OTP" — golden primary button
- Terms & Privacy — small legal text at bottom

### 2. OTP Verification
- 6 individual digit input boxes
- Soft glowing "Verify" button
- Resend OTP timer
- Calm animated background stars

### 3. Language Selection
- Title: "Select Your Language"
- Options: Tamil, Hindi, English, Telugu, Kannada
- Rounded selection cards
- Gold highlight on selected
- "Confirm" button

### 4. Dashboard
- Greeting: "Good Evening, [Child Name]"
- Category chips: All, Bedtime, Moral, Animals, Mythology
- 2-column story grid
- Card: illustration + title + duration + soft glow
- Floating "New Story" button (gold)

### 5. Story Player
- Large glowing crescent moon
- Story illustration
- Large Play/Pause button (gold)
- Progress bar
- Sleep timer control
- Minimal controls

### 6. Generate Story
- Child name dropdown
- Theme selector
- Large golden CTA button
- Soft card layout

### 7. Subscription
- Premium badge
- Plan cards
- Benefits list
- Golden CTA button

### 8. Success
- Glowing golden star illustration
- "Success!" title
- "Explore stories" button (soft blue)

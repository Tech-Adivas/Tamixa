# Tamixa — Features Implemented (Feb 2026)

Features implemented in this session (excluding offline download).

---

## 1. Favorites

- **Backend**: `favorite_story` table, `FavoriteStoryController` (GET, POST, DELETE, check)
- **Web**: Favorites tab on Stories page, heart toggle on curated/generated stories
- **Mobile**: `StoryApi` extended with `getFavorites`, `addFavorite`, `removeFavorite`, `isFavorite`

## 2. Subscription management

- **Backend**: `SubscriptionController` already had GET /subscription; added GET `/subscription/usage` with storiesUsed, storiesLimit, voiceUsed, voiceLimit
- **Web**: `/subscription` page showing plan, status, usage, cancel at period end

## 3. Voice profiles

- **Backend**: Existing `VoiceController` (upload, list, getById)
- **Web**: `/voice` page — list profiles, upload new voice sample

## 4. Listening progress

- **Backend**: `ListeningProgressController` — GET `/listening-progress?days=30` — storiesStarted, storiesCompleted, completionRate
- **Web**: Shown on Settings page

## 5. Consent recording & dashboard

- **Backend**: `parent_consent` table, `ConsentService`, `ConsentController` (list, record)
- **Web**: Settings page shows consent history; registration records `registration_terms` consent

## 6. Data export

- **Backend**: `data_export_job` table, `DataExportService`, `DataExportController` — request export, list jobs (status, download URL when ready)
- **Web**: Settings page — request export, view job status; **Backend**: Data export file generation (JSON) uploaded to S3, presigned download URL, scheduled processor every 2 min

## 7. Passwordless magic link

- **Backend**: `magic_link_token` table, `MagicLinkService`, AuthController endpoints — POST `/auth/magic-link/request`, GET `/auth/magic-link/verify?token=`
- **Web**: Login page "Send magic link" button; `/auth/magic-link?token=...` page verifies and signs in (dev: link logged to backend)

## 8. Feedback

- **Backend**: `story_feedback` table, `FeedbackService`, `FeedbackController` — POST `/feedback` (storyId, rating, comment)
- **Web**: Feedback form on Stories page

## 9. Accessibility

- **Web**: Settings — text size slider (font scale), high-contrast toggle; CSS variables `--font-size-scale`, `body.high-contrast`

## 10. High-Impact Engagement (Feb 2026)

- **Achievements & badges**: Per-child badges for story completions (First Story, Story Explorer 5, Champion 10, Master 25, Legend 50). Requires `childId` in analytics when completing. `GET /achievements/children/{id}`, `GET /achievements/definitions`. Dashboard shows badges.
- **Resume playback (Continue where you left off)**: Save/load last position per story. `POST /playback/position`, `GET /playback/position?storyId=&storySource=`, `GET /playback/recent`. Dashboard "Continue listening" section.
- **Story recommendations**: Personalized mix of curated + generated by favorites and child interests. `GET /stories/recommended?childId=&language=`.

## 11. Creative & Personalization (Feb 2026)

- **Story illustrations / Regenerate cover**: AI-generated cover images via DALL-E 3. `POST /stories/{id}/regenerate-cover`. Images stored in GCS when CDN enabled. Cover shown in story list.
- **Character builder**: Child profile extended with `favoriteColor`, `favoriteAnimal`, `characterTraits`, `avatarChoice`. Used in story generation prompt. Web/mobile: create + PATCH to edit.
- **Soundscapes**: `GET /soundscapes` (permitAll) returns rain, forest, waves, fireplace, night. Web: ambient player during story time.
- **Story remix**: `POST /stories/{id}/remix` with `{ remixInstruction }` (e.g. "make the dragon friendly"). Creates new personalized variant.

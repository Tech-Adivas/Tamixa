# Tamixa Premium UX - Quick Start Guide

## For Parents

### 5-Minute Setup

1. **Download the App**
   - iOS: App Store → Search "Tamixa"
   - Android: Google Play → Search "Tamixa"

2. **Create Account**
   - Open app
   - Tap "Sign Up"
   - Enter email and password
   - Verify email

3. **Complete Onboarding**
   - Swipe through welcome screens
   - Try the interactive story demo (optional)
   - Skip voice/avatar setup for now (can do later)

4. **Start Listening**
   - Browse spotlight stories on dashboard
   - Tap any story to start playing
   - Enjoy!

### First Story Recommendations

**For Ages 3-5**:
- "The Friendly Forest" (5 min)
- "Bedtime Stars" (7 min)
- "Rainbow Adventure" (6 min)

**For Ages 6-8**:
- "The Brave Explorer" (12 min)
- "Mystery of the Lost Treasure" (15 min)
- "Learning to Share" (10 min)

**For Ages 9-12**:
- "The Time Traveler's Choice" (20 min, interactive)
- "Science Detective" (18 min)

### Quick Tips

**Build a Routine**:
- Set a daily listening time (bedtime works great)
- Track your streak in the profile
- Aim for 10-15 minutes per day

**Explore Categories**:
- Adventure: Exciting stories
- Learning: Educational content
- Fun: Pure entertainment
- Safety: Life skills

**Try Interactive Stories**:
- Look for "Interactive" badge
- Let your child make choices
- Replay to try different paths

## For Content Creators

### Create Your First Story

**5-Minute Story Creation**:

1. **Log In**
   - Go to admin.tamixa.com
   - Enter credentials
   - Navigate to "Stories"

2. **Click "+ New Story"**

3. **Fill Basic Info**:
   ```
   Title: The Curious Cat
   Category: Adventure
   Content: Once upon a time, there was a curious cat named Whiskers...
   Moral: Curiosity leads to discovery
   ```

4. **Save Draft**
   - Click "Save Draft"
   - Story saved, not yet published

5. **Submit for Review**
   - Click "Submit for Review"
   - Pipeline starts automatically
   - Wait 5-10 minutes for processing

6. **Approve & Publish**
   - Review translations
   - Listen to audio samples
   - Click "Approve & Publish"
   - Story goes live!

### Story Writing Tips

**Keep It Simple**:
- Clear, age-appropriate language
- Short sentences for younger audiences
- Engaging opening hook

**Structure**:
- Beginning: Introduce character and setting
- Middle: Present challenge or adventure
- End: Resolution and lesson learned

**Length Guidelines**:
- Ages 3-5: 300-500 words (5-7 min)
- Ages 6-8: 500-1000 words (8-12 min)
- Ages 9-12: 1000-2000 words (15-20 min)

**Include a Moral**:
- What should children learn?
- Keep it simple and clear
- Relate to real-life situations

### Quick Actions

**Approve Story**:
1. Stories → Find story with READY status
2. Click story title
3. Review content and audio
4. Click "Approve & Publish"

**Regenerate Failed Audio**:
1. Stories → Find story with failed audio
2. Click "Narration" tab
3. Click "Regenerate" for failed language
4. Wait for completion

**View Metrics**:
1. Click "AI Metrics" in navigation
2. Select time period
3. Review key metrics
4. Export if needed

## Common Tasks

### Mobile App

**Change Playback Speed**:
1. Open story player
2. Tap speed indicator (e.g., "1.0x")
3. Select desired speed

**Mark Story as Favorite**:
1. Open story player
2. Tap heart icon
3. Find in Profile → Favorites

**Track Progress**:
1. Go to Profile
2. View learning metrics
3. Check life skills progress

**Generate Custom Story**:
1. Tap "+" in bottom navigation
2. Select child
3. Choose theme
4. Customize details
5. Tap "Generate"

### Admin Dashboard

**Search for Story**:
1. Go to Stories page
2. Use search bar at top
3. Enter title or keyword
4. Press Enter

**Filter Stories**:
1. Click filter dropdown
2. Select status, category, or language
3. Results update automatically

**Bulk Approve**:
1. Select multiple stories (checkboxes)
2. Click "Bulk Actions"
3. Select "Approve & Publish"
4. Confirm action

**Export Metrics**:
1. Go to AI Metrics
2. Click "Export" button
3. Select format (CSV, JSON, Excel)
4. Choose date range
5. Click "Download"

## Troubleshooting

### Mobile App

**Story Won't Play**:
1. Check internet connection
2. Close and reopen app
3. Update to latest version

**Progress Not Saving**:
1. Ensure you're logged in
2. Check internet connection
3. Wait a few seconds for sync

**App Crashes**:
1. Restart device
2. Update app
3. Clear app cache (Settings → Storage)

### Admin Dashboard

**Can't Log In**:
1. Check email/password
2. Reset password if needed
3. Clear browser cache
4. Try different browser

**Story Won't Submit**:
1. Check all required fields filled
2. Verify content length (< 10,000 chars)
3. Refresh page and retry

**Metrics Not Loading**:
1. Refresh page
2. Check internet connection
3. Try different time period
4. Contact support if persists

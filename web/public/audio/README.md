# Login page ambient sound

Place a calm, loopable audio file here:

- **`calm-ambient.mp3`** – played on the login screen when the user taps "Play sound". Use a short, seamless loop (e.g. soft pad, gentle nature, or quiet music). Keep volume low so it stays in the background.

If the file is missing, the Play sound button still appears; playback will simply fail until you add the file.
